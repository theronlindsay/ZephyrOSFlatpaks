flatpaks

A curated Flatpak repository bringing system tools and utilities to ZephyrOS and other Fedora Atomic-style Linux distributions.

Add Repository File View Repo GitHub

1. Enable ZephyrOS Repository

To access the flatpaks, add the ZephyrOS Flatpak remote repo to your Linux system configuration by running the command below in your terminal:

flatpak remote-add --if-not-exists zephyros https://repo.zephyros.buzz/index.flatpakrepo

2. Available Applications

ZephyrOS Hello

buzz.zephyros.hello

An elegant and lightweight welcome utility and system dashboard crafted for ZephyrOS, welcoming users and presenting system information in a beautiful user interface.

Installation Command

flatpak install zephyros buzz.zephyros.hello
